# 青简剪贴板

复制过的东西都记下来，按快捷键从屏幕一边弹出，选中就粘贴回原来的窗口。开源免费，可以单独安装，也随青简输入法内置。

## 下载

到 [Releases](../../releases) 下载 `qingjian-clipboard-<版本>-windows-x86_64-setup.exe`，双击安装。

- 支持 Windows 10 1809 及以上的 64 位系统。
- 只装在当前用户下，不需要管理员权限。
- 安装包暂时没有代码签名，SmartScreen 拦截时点「更多信息 → 仍要运行」。

已经装了[青简输入法](https://github.com/qingjian-team/qingjian)的话不用另装：在「设置 → 实验功能」里打开青简剪贴板就行。

## 怎么用

- 按 **Ctrl + Alt + V** 呼出面板，点一张卡片或按回车就粘贴回刚才的窗口。
- 直接打字就是搜索；顶上可以按文字、代码、图片、文件筛选。
- 右键一张卡片可以只复制、编辑或删除。
- 托盘图标的右键菜单里可以暂停记录、退出；单独安装时还能开关开机启动。

快捷键和面板从哪条边弹出，在青简的设置里改；单独安装时改配置文件 `%APPDATA%\Qingjian\config.toml` 里的 `[clipboard]` 一节与 `[shortcut] clipboard`。

## 功能

- 记文字、带格式的文字、代码、图片和文件；代码带高亮，图片显示缩略图，文件显示大小。
- 面板可以从屏幕的上、下、左、右弹出：上下弹出时卡片横着排，左右弹出时竖着排。
- 可以暂停记录、设置不记录哪些程序（缺省已排除常见的密码管理器），设置最多保存多少条。
- 托盘图标跟随任务栏的深浅色。

## 局域网同步

和同一个网络里的其他 Windows 电脑互传复制的文字和图片。和青简输入法 Android 版互传要等输入法的下一个版本。

- 缺省关闭，打开之后才会在局域网里出现。
- 两台设备第一次连接时输一次 6 位配对码，之后自动同步。
- 内容加密后直接在设备之间传，不经过任何服务器。
- 两边都在线时才传；离线期间复制的内容，下次连上时自动补齐。

## 隐私

复制的内容只存在你自己的电脑上（`%LOCALAPPDATA%\Qingjian\clipboard`），不上传。密码管理器标记为「别记录」的内容不会被记下。卸载不会删除历史，不要了可以直接删掉这个文件夹。
