# 青简剪贴板

可搜索、可编辑的剪贴板历史。开源免费，可以单独使用，也可以在青简输入法的设置里打开。

> 还在开发中，暂时没有可下载的版本。

## 功能

- 按快捷键呼出历史，面板可以从屏幕的上、下、左、右弹出
- 滚动浏览、搜索，选中后粘贴回原来的窗口
- 显示文字、代码和图片
- 右键删除或编辑

计划中：多端同步（端到端加密）。
